# 🤖 DecodeLabs Rule-Based AI Chatbot

## 📌 Project Overview
This project was developed as part of the Artificial Intelligence Internship at DecodeLabs.

The chatbot is a Rule-Based AI system developed using Python.  
It simulates human conversation using predefined logical rules, keyword matching, and decision-making conditions.

This project focuses on foundational Artificial Intelligence concepts such as:
- Control Flow
- Decision-Making Logic
- Conversational Interaction
- Pattern Recognition
- Continuous User Interaction

# 🧠 AI Logic Used

This chatbot uses Rule-Based Artificial Intelligence.

Instead of Machine Learning, the chatbot works using:
- if-else decision-making
- keyword matching
- conversational flow
- predefined response patterns
- continuous interaction loop

The chatbot simulates intelligent conversation by analyzing user input and responding according to programmed rules.
